# Source access

Project: **What OCR Evaluation Reveals and Conceals: Reference Integrity, Text Representation, and Retrieval Diagnostics for Printed Kazakh Book OCR**

Study-use permissions for the book scans, digital references and archived OCR outputs were confirmed by the authors. Public redistribution permission and unrestricted reviewer access have not been established. The particular source materials are excluded from this package.

metadata/restricted_inputs.json identifies 15 excluded inputs by portable alias, byte length, SHA-256 and original repository-relative path. Those paths document provenance. They are not public download locations or implicit filesystem dependencies. The inputs comprise six A files, four B files and five saved correction/reference files.

The scan pages, 43-page digital PDF, 72-page prose scan, stored inference images, full extraction JSON, private notebooks, full HTML diffs and candidate-reference passages are also excluded. The original Tesseract B source PDF is unavailable. A metadata hash identifies an existing copy; it does not supply permission or authenticate every historical inference step.

Public arithmetic, conditional page-count resampling, current figure generation, numeric representation checks and synthetic software tests work without those inputs. Fresh alignments and historical rankings require the exact separately authorized text copies. Visual reference/edition findings and notebook routing cannot be independently re-established from aggregate records alone.

No external access arrangement, custodian service or input download is promised. Readers who already lawfully possess the exact materials can use the input-root commands in README.md. Authorized inputs belong in a sibling folder outside the public package. A different edition is not an interchangeable input for archived-output verification.

The authors' manuscript approval is confirmed. A new decision is needed only if a specific source-access or redistribution arrangement will be offered. Public code-and-aggregate release does not require publishing the restricted materials.
